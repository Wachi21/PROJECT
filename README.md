🏫 KMITL Classroom Booking System (v3)KMITL Classroom Booking คือ เดสก์ท็อปแอปพลิเคชัน (Desktop Application) สำหรับระบบบริหารจัดการและจองห้องเรียนออนไลน์ พัฒนาขึ้นด้วยภาษา Python (Tkinter) ร่วมกับฐานข้อมูล MySQL เหมาะสำหรับใช้งานในระดับสถาบันหรือคณะ เพื่ออำนวยความสะดวกแก่อาจารย์และนักศึกษาในการจัดสรรพื้นที่สำหรับการเรียน การสอนเสริม การติวสอบ หรือการทำงานกลุ่มได้อย่างเป็นระเบียบ🌟 จุดเด่นและฟีเจอร์หลัก (Key Features)🔐 ระบบจัดการสมาชิกและเข้าสู่ระบบ (Authentication System):สมัครสมาชิกโดยแยกบทบาทเป็น นักศึกษา 🎓 หรือ อาจารย์ 📚รองรับการล็อกอินด้วย ชื่อ-นามสกุล หรือ ⚙️ ขั้นตอนการติดตั้งและการรันโปรแกรม (Getting Started)1. ความต้องการของระบบ (Prerequisites)Python 3.8+MySQL Server 8.0+ (หรือผ่าน XAMPP / MySQL Workbench)2. การติดตั้งไลบรารีเปิด Terminal / Command Prompt แล้วพิมพ์คำสั่ง:pip install mysql-connector-python
3. การเตรียมฐานข้อมูล (Database Setup)เปิดโปรแกรม MySQL Workbench แล้วเชื่อมต่อกับ MySQL Server ในเครื่องของคุณเปิดไฟล์สคริปต์ classroom_booking_mysql.sqlสั่ง Execute (กดไอคอนสายฟ้า ⚡) เพื่อสร้างฐานข้อมูลชื่อ project พร้อมตารางและ Triggers ทั้งหมด4. การตั้งค่ารหัสผ่านฐานข้อมูล (Configuration)เปิดไฟล์ projectxworkbench.py แล้วแก้ไขตัวแปร MYSQL_CONFIG ในโค้ด (ช่วงประมาณบรรทัดที่ 220) ให้ตรงกับรหัสผ่าน MySQL เครื่องของคุณ:MYSQL_CONFIG = {
    "host": "localhost",
    "port": 3306,
    "user": "root",
    "password": os.environ.get("DB_PASSWORD", "YOUR_MYSQL_PASSWORD"),  # ใส่รหัสผ่าน MySQL ของคุณที่นี่
    "database": "project",
    "charset": "utf8mb4",
}
5. สั่งรันแอปพลิเคชันpython projectxworkbench.py
🗄️ โครงสร้างฐานข้อมูล (Database Schema)users : เก็บข้อมูลสมาชิก (user_id, role, first_name, last_name, email, password_hash)rooms : เก็บรายชื่อห้องเรียน ความจุ อาคาร และสีประจำห้องequipment & room_equipment : เก็บข้อมูลอุปกรณ์และจำนวนอุปกรณ์ประจำแต่ละห้อง (Many-to-Many)time_slots : เก็บคาบเวลา (08:00 – 18:00 น.)bookings : เก็บข้อมูลการจองปัจจุบัน มี UNIQUE KEY (room_id, booking_date, slot_id) กันการจองซ้ำbooking_details : เก็บข้อมูลเพิ่มเติมของการจอง (รหัสประจำตัว, เบอร์โทร, จำนวนผู้เข้าใช้)history : เก็บประวัติการจองและยกเลิก (บันทึกอัตโนมัติผ่าน Database Triggers)👥 ผู้จัดทำและบทบาทหน้าที่ (Development Team - Agile Model)พัฒนาภายใต้แนวคิด Agile Methodology โดยแบ่งบทบาทการทำงานในทีมดังนี้:ชื่อ-นามสกุลรหัสนักศึกษาบทบาทในโปรเจกต์ (Agile Role)Responsibilitiesนาย ณัฐพัฒน์ ศรีเตชะ69030325Product Ownerวางแผนโครงงาน จัดลำดับความสำคัญของฟีเจอร์ และควบคุมขอบเขตระบบนางสาว ภูริชญา โฉมศรี69030195Database Designerออกแบบ ER-Diagram, Schema, เขียน SQL Script และจัดการ Triggersนาย ภัทรกร อินทรกำแหง69040442UI/UX Designerออกแบบโครงร่าง UI, Theme, Layouts และสร้าง Custom Componentsนาย วชิรวิทย์ ขุนนุช69030210Software Tester & Core Developerทดสอบระบบ (Testing), จัดการ Security/Auth และปรับปรุงคุณภาพโค้ด📄 ใบอนุญาต (License)โครงงานนี้จัดทำขึ้นเพื่อการศึกษา รายวิชาการพัฒนาซอฟต์แวร์ สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (KMITL)
